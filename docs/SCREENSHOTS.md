## What to look for

- **Times in the right zone:** in-person events on the venue's clock with "Your time" below when it differs; online events on the phone's clock; Discover's "Tomorrow" is the phone's day (Midnight Code Jam is Monday night in New York, Tuesday morning in Lahore).
- **The server's word and the user's, apart:** after a published update the tickets say Moved and Cancelled; the saves and the tickets themselves are untouched.
- **Never color alone:** Going, Moved, Cancelled, clashes and places left each have an icon or a word.
- **Notifications from the data:** the plan lists only events you're going to (or saved with a reminder), each a lead time before; the alerts say what moved, to when, and from when.
- **Platform touches:** iOS switches and the time wheel on iOS; Material switches and wallpaper colors on Android.
- **Large text:** text wraps rather than truncating, segments become radio buttons, and the tab labels keep their size (a long press shows them). One known limit: Discover's carousels cut long titles at AX3 (the [roadmap](ROADMAP.md) has it).

## Retaking them

```bash
fvm flutter build ios --simulator --debug
xcrun simctl uninstall booted co.bitfuse.flutter.evently          # a fresh install
xcrun simctl install booted build/ios/iphonesimulator/Runner.app
xcrun simctl launch booted co.bitfuse.flutter.evently             # then London, and Explore with demo data

xcrun simctl status_bar booted override --time 9:41 --dataNetwork wifi --wifiBars 3 --cellularBars 4 --batteryState charged --batteryLevel 100
xcrun simctl ui booted appearance dark                            # or light
xcrun simctl ui booted content_size accessibility-extra-large     # AX3; "large" is the default

xcrun simctl io booted screenshot docs/screenshots/<name>.png
sips -Z 1000 docs/screenshots/<name>.png                          # downscale (macOS)

xcrun simctl status_bar booted clear                              # afterwards
```

On Android: `adb exec-out screencap -p > docs/screenshots/<name>.png`, then the same `sips` step. The alerts: Settings → Developer → Publish a catalog update, then Run background sync now, with notifications on.
